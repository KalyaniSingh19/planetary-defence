What-If Parameter

LD Threshold — Numeric Range, Min 0.5, Max 20, Increment 0.5, Default 5. Drives the measure below and its own slider + card visual on the page.

Approaches Within Threshold =
VAR Threshold = SELECTEDVALUE('LD Threshold'[LD Threshold], 5)
RETURN CALCULATE([Total Approaches], FILTER(Fact_approaches, Fact_approaches[Distance_LD] <= Threshold))

Why this page matters

Instead of a single static "close approach" definition, a viewer can drag the threshold slider and instantly see how many recorded approaches fall inside their own chosen distance — turning a fixed dataset into a live risk-framing tool.
